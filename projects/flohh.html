📌 Was ist es?

flohh ist eine portable App für den PC-Umzug – Daten springen von Rechner zu Rechner. Bibliotheken und Ordner wandern von einem Rechner auf einen anderen, zwischen Windows, Linux und macOS in allen Richtungen. Per LAN-Kabel, über den Router (LAN oder WLAN) oder per Thunderbolt/USB4 – ohne Installation, ohne Cloud, ohne Konto, ohne externes Laufwerk. Gebaut mit Go, die Oberfläche öffnet sich im Browser.

Bereits jetzt möglich:

🔍 Rechner finden sich von selbst im Netz
🔐 Verschlüsselte Kopplung per 6-stelligem Code
📁 Dokumente, Bilder, Musik, Videos, Schreibtisch, Downloads
🗂️ Auch eigene und versteckte Ordner (z. B. AppData)
🛡️ Nichts wird überschrieben
⏯️ Abgebrochene Übertragungen fortsetzbar
🔌 LAN, WLAN, Thunderbolt/USB4, USB-LAN-Adapter
💾 Portabel – direkt vom USB-Stick starten
📥 Wo bekomme ich es?

Als einzelne ausführbare Datei für Windows, Linux und macOS – jeweils für Intel/AMD und ARM. Am einfachsten: das ZIP mit allem laden und auf einen USB-Stick entpacken – dann hat man für jeden Rechner die passende Datei dabei.

📦 ZIP mit allem (empfohlen) Alle Systeme · für den USB-Stick 🪟 Windows – EXE x64 / ARM64 · Keine Installation 🐧 Linux x86_64 / ARM64 · Keine Installation 🍎 macOS Intel / Apple Silicon

Starten: Datei auf beiden Rechnern ausführen – die Oberfläche öffnet sich im Standardbrowser.

Linux: Datei ausführbar machen und im Terminal starten:

chmod +x flohh-*-linux-x86_64
./flohh-*-linux-x86_64

macOS: Die Dateien sind (noch) nicht von Apple notarisiert. Vom USB-Stick gestartet läuft flohh direkt. Im Browser heruntergeladen: einmal starten, dann unter Systemeinstellungen → Datenschutz & Sicherheit auf „Dennoch öffnen“ klicken – oder im Terminal:

xattr -d com.apple.quarantine flohh-*

Windows: Beim ersten „Empfangen“ fragt die Windows-Firewall einmal nach – „Zugriff zulassen“ wählen.
