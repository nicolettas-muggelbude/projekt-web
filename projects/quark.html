📌 Was ist es?

Quark ist ein kostenloser, werbefreier QR-Code-Generator als Desktop-App für Linux und Windows. URL eingeben, QR-Code live vorschauen, als PNG exportieren – ohne Tracking, ohne Werbung, ohne Cloud.

Bereits jetzt möglich:

🔗 URL eingeben, QR-Code live vorschauen
📷 PNG-Export in 256 / 512 / 1024 px
🐧 Linux – AppImage, keine Installation nötig
🪟 Windows – EXE-Installer
🚫 Kein Tracking, keine Werbung
🔒 Alles lokal – keine Cloud, kein Internet nötig
📥 Wo bekomme ich es?

Als AppImage (Linux) oder EXE (Windows) – direkt herunterladen. Optional mit install-linux.sh für Desktop-Integration.

📦 Linux – AppImage herunterladen x86_64 · Keine Installation 🪟 Windows – EXE herunterladen x64 · Setup-Installer

Desktop-Integration für Linux (empfohlen):

AppImage und install-linux.sh herunterladen, dann:

chmod +x install-linux.sh
./install-linux.sh Quark_amd64.AppImage

Das Script kopiert das AppImage in einen stabilen Pfad, prüft Abhängigkeiten und erstellt einen Starter für GNOME, KDE, XFCE und weitere Desktop-Umgebungen.
