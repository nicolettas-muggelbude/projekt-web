# MyApps v0.2.3 - Dein Überblick über installierte Linux-Apps

**Weißt du eigentlich, was du alles auf deinem Linux-System installiert hast? 🤔**

**Release-Datum:** 28. Dezember 2025

---

## 🖥️ Was ist MyApps?

**MyApps** ist ein benutzerfreundliches Tool für Linux, das dir **auf einen Blick** zeigt, welche Anwendungen auf deinem System installiert sind - **ohne den ganzen System-Clutter**.

**Das Problem:**
- Paketmanager zeigen tausende Pakete (System-Libraries, Treiber, Dependencies...)
- Schwer zu finden: "Welche Apps habe ich eigentlich installiert?"
- Keine übersichtliche Darstellung

**Die Lösung - MyApps:**
- ✨ Zeigt nur **echte Anwendungen** (keine System-Pakete)
- 🎨 Moderne, übersichtliche Oberfläche mit Dark Mode
- 🔍 Intelligentes Filtern - nur was du wirklich brauchst
- 📤 Export als Liste (TXT, CSV, JSON)
- 🌍 Funktioniert auf allen gängigen Linux-Distributionen

**Perfekt für:**
- System-Aufräumarbeiten ("Was kann ich deinstallieren?")
- Inventarisierung ("Was habe ich alles installiert?")
- Backup-Planung ("Welche Apps muss ich neu installieren?")
- Neugierige Linux-User 😊

---

## 🎨 Wie sieht das aus?

MyApps bietet eine moderne **GTK4-Oberfläche** mit:
- **Listenansicht** - übersichtlich mit Icons
- **Tabellenansicht** - kompakt mit allen Infos
- **Dark Mode** - folgt deinem System-Theme
- **Suchfunktion** - finde Apps blitzschnell

**Unterstützt werden:**
- Debian, Ubuntu, Linux Mint
- Arch Linux, Manjaro
- Fedora, RHEL, CentOS
- openSUSE
- Solus
- Snap & Flatpak (überall)

## 📦 MyApps ausprobieren

### Noch nie installiert? So geht's:

**Option 1: OBS-Pakete** (Empfohlen für Debian/Ubuntu/Fedora/openSUSE)

```bash
# Beispiel für Ubuntu 24.04:
echo "deb https://download.opensuse.org/repositories/home:/nicoletta:/myapps/Ubuntu_24.04/ /" | sudo tee /etc/apt/sources.list.d/myapps.list
wget -qO- https://download.opensuse.org/repositories/home:/nicoletta:/myapps/Ubuntu_24.04/Release.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/myapps.gpg
sudo apt update && sudo apt install myapps
```

→ [Alle 11 OBS-Distributionen](https://software.opensuse.org//download.html?project=home%3Anicoletta%3Amyapps&package=myapps)

**Option 2: AUR** (Arch Linux)

```bash
yay -S myapps
# oder
paru -S myapps
```

### Bereits installiert? Einfach updaten:

```bash
# Debian/Ubuntu/Mint
sudo apt update && sudo apt upgrade myapps

# Arch Linux
yay -Syu myapps

# Fedora
sudo dnf update myapps

# openSUSE
sudo zypper refresh && sudo zypper update myapps
```
